# モデル・画像 アセット

このゲームの3Dモデルと画像(テクスチャ)は現在すべて **コードで生成** しています（`src/models.js`）。
デザイナーが作ったデータ（.glb / .png）に差し替えられるように、以下の仕組みを用意しています。
**3Dモデル**は下記、**画像(テクスチャ)**は末尾の「画像(テクスチャ)一覧」を参照。

## フォルダ構成（A / B 運用）

| フォルダ | 役割 |
| --- | --- |
| `assets/reference/` | **A：リファレンス**。現行のコード生成モデル(.glb)・画像(.png)を書き出した一式。デザイナーに「今の見た目・寸法・向き」を渡すための見本。 |
| `assets/models/` | **B：差し替え(モデル)**。デザイナーが作った .glb を置く場所。ここに `<key>.glb` があれば、ゲームはそれを優先して読み込む。無ければコード生成モデルにフォールバック。 |
| `assets/textures/` | **B：差し替え(画像)**。デザイナーが直した .png を置く場所。ここに `<key>.png` があれば、ゲームはそれを優先して読み込む。無ければコード生成テクスチャにフォールバック。 |

進め方：Aの一式を見本として渡す → デザイナーがBに納品 → **1モデルずつ確認しながら組み込み**。

## リファレンスの書き出し方（Aフォルダ）

開発サーバを起動（`npm run dev`）してから：

- **3Dモデル(.glb)**：ブラウザで `/export.html` を開き「すべてダウンロード」→ `assets/reference/` に置く。
- **画像(.png)**：ブラウザで `/export-textures.html` を開き「すべてダウンロード」→ `assets/reference/` に置く。

（書き出しツールは開発用。本番ビルド `dist` には含まれません。）

## モデル一覧

`assets/models/<ファイル名>` に置くと差し替わります（キーは `src/modelLoader.js` の `MODEL_FILES`）。

| キー | ファイル名 | 内容 | 動くパーツ（ノード名） |
| --- | --- | --- | --- |
| rabbit | `rabbit.glb` | プレイヤー兎 | `rig`(伸縮・ホップ), `ear_0..3`(耳), `snack`(食事用ニンジン/通常非表示), `foot_*`, `arm_*` |
| goalRabbit | `goal-rabbit.glb` | ゴールで待つピンク兎 | `rig`(呼吸), `ear_0..3` |
| whirl | `whirl.glb` | つむじ風(乗ると対の落ち葉マスへ運ぶ) | `spin`(常時回転させる内側グループ) |
| leafBase | `leaf-base.glb` | 落ち葉マスの土台(つむじ風の飛び先。機能は畑と同じ) | なし ※実際のゲームでは落ち葉柄のテクスチャ(Canvas生成)を貼っている。reference の .glb は単色フォールバック版なので、実物の見た目はゲーム画面を参照 |
| carrot | `carrot.glb` | ニンジン1本 | なし |
| spring | `spring.glb` | ジャンプ台のバネ | なし（マス全体を上下スケール） |
| cart | `cart.glb` | トロッコ | `cart`(本体), `wheel_0..3`(車輪回転) |
| sled | `sled.glb` | ソリ（冬） | `cart`(本体)。車輪なし |
| goal | `goal.glb` | ゴールの祠（台座＋旗＋兎） | `flag`(旗), `goal_rabbit`(中の兎) |
| mound | `mound.glb` | 畑マスの土台 | なし |
| islandBase | `island-base.glb` | 島の土台（水面＋草地の円盤） | なし |
| tree | `tree.glb` | 背景の木（春の色で書き出し。`tree-winter.glb` は冬＝雪付きの参考） | なし |
| rock | `rock.glb` | 背景の岩 | なし |
| flower | `flower.glb` | 背景の花 | なし |

> 背景（islandBase / tree / rock / flower）は、**配置（島のまわりに散らす）と季節ごとの色付けはコード側**で行っています。差し替えるのは1個ぶんの「見た目」で、それをコードが並べます。木は春の色で書き出していますが、実際は季節ごとに色が変わります（冬は雪付き＝`tree-winter.glb` を参照）。

## 制作ルール（重要）

- **単位**：1マス = ワールド1.0。段差1段の高さ `HSTEP = 0.35`。
- **原点(pivot)**：足元＝地面 `y = 0`。接地物は原点が接地面になるように。
- **正面**：モデルの前 = **+Z 方向**（農夫の視線・兎の顔が向く向き）。Y-up。
- **実寸の基準**：`assets/reference/` の .glb を「今の正しいサイズ・向き・原点」の基準にしてください。
- **スタイル**：ローポリ／フラットシェーディング寄り。マテリアルは PBR（glTF標準）でOK。
- **パーツ分け**：上表の「動くパーツ」は**別ノードに分け、同じ名前を付けて**ください。名前が一致していると、耳ピクッ・ホップ・車輪回転などのアニメをそのまま流用できます（一致しない場合は組み込み時に手で対応付けます）。

## アニメーションについて

現在のアニメ（耳ピクッ、ホップ、呼吸、車輪回転、旗揺れ、食事）は
`src/scene3d.js` がモデル内の該当ノードを毎フレーム動かして表現しています。
glb に差し替える際は、上表のノード名を合わせておくと流用が楽です。
ボーン／glTFアニメーションでの差し替えも可能ですが、その場合は組み込み時に個別対応します。

# 画像(テクスチャ)一覧

ゲーム中の「画像」は現在 Canvas でコード生成しています（`src/models.js`）。
`assets/textures/<ファイル名>` に置くと差し替わります（キーは `src/textureLoader.js` の `TEXTURE_FILES`）。
モデルと違いアニメ依存が無いので、**.png を置くだけで即反映**されます。

| キー | ファイル名 | サイズ | 内容 |
| --- | --- | --- | --- |
| number1 | `number-1.png` | 128×128 | 数字バッジ「1」（原作準拠で青）。全マスの数字表示に使用 |
| number2 | `number-2.png` | 128×128 | 数字バッジ「2」（ピンク） |
| number3 | `number-3.png` | 128×128 | 数字バッジ「3」（赤） |
| leaf | `leaf.png` | 256×256 | 落ち葉マス(つむじ風の対＝飛ばされる先)のテクスチャ。上面・側面に貼る |

## 画像の制作ルール

- **数字バッジ**：透過PNG推奨。マスの上に立つスプライト(ビルボード)として中央に表示。数字が読みやすいよう縁取り込みで。3枚(1/2/3)は同じ余白・字面サイズで揃えると見た目が安定します。
- **落ち葉テクスチャ**：不透明でOK。上下左右がつながる（タイル化しても継ぎ目が出にくい）と、側面と上面の境目がきれいになります。
- **色space**：sRGB前提で読み込みます（普通に描いた見た目でOK）。
- **差し替え確認**：`/export-textures.html` で現行画像を書き出し、それを叩き台に上書きするのが確実です。
