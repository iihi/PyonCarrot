# 3Dモデル アセット

このゲームのモデルは現在すべて **コードで生成** しています（`src/models.js`）。
将来デザイナーが作った 3D データ（.glb）に差し替えられるように、以下の仕組みを用意しています。

## フォルダ構成（A / B 運用）

| フォルダ | 役割 |
| --- | --- |
| `assets/reference/` | **A：リファレンス**。現行のコード生成モデルを書き出した .glb 一式。デザイナーに「今の見た目・寸法・向き」を渡すための見本。 |
| `assets/models/` | **B：差し替え**。デザイナーが作った .glb を置く場所。ここに `<key>.glb` があれば、ゲームはそれを優先して読み込む。無ければコード生成モデルにフォールバック。 |

進め方：Aの一式を見本として渡す → デザイナーがBに納品 → **1モデルずつ確認しながら組み込み**。

## リファレンスの書き出し方（Aフォルダ）

1. 開発サーバを起動（`npm run dev`）。
2. ブラウザで `/export.html` を開く。
3. 「すべてダウンロード」で .glb 一式をダウンロード。
4. ダウンロードした .glb を `assets/reference/` に置く。

（書き出しツールは開発用。本番ビルド `dist` には含まれません。）

## モデル一覧

`assets/models/<ファイル名>` に置くと差し替わります（キーは `src/modelLoader.js` の `MODEL_FILES`）。

| キー | ファイル名 | 内容 | 動くパーツ（ノード名） |
| --- | --- | --- | --- |
| rabbit | `rabbit.glb` | プレイヤー兎 | `rig`(伸縮・ホップ), `ear_0..3`(耳), `snack`(食事用ニンジン/通常非表示), `foot_*`, `arm_*` |
| goalRabbit | `goal-rabbit.glb` | ゴールで待つピンク兎 | `rig`(呼吸), `ear_0..3` |
| human | `human.glb` | 農夫 | `rig`(内側グループ)。向き回転・走り寄りは親グループを操作 |
| carrot | `carrot.glb` | ニンジン1本 | なし |
| spring | `spring.glb` | ジャンプ台のバネ | なし（マス全体を上下スケール） |
| cart | `cart.glb` | トロッコ | `cart`(本体), `wheel_0..3`(車輪回転) |
| sled | `sled.glb` | ソリ（冬） | `cart`(本体)。車輪なし |
| goal | `goal.glb` | ゴールの祠（台座＋旗＋兎） | `flag`(旗), `goal_rabbit`(中の兎) |
| mound | `mound.glb` | 畑マスの土台 | なし |

## 制作ルール（重要）

- **単位**：1マス = ワールド1.0。段差1段の高さ `HSTEP = 0.35`。
- **原点(pivot)**：足元＝地面 `y = 0`。接地物は原点が接地面になるように。
- **正面**：モデルの前 = **+Z 方向**（農夫の視線・兎の顔が向く向き）。Y-up。
- **実寸の基準**：`assets/reference/` の .glb を「今の正しいサイズ・向き・原点」の基準にしてください。
- **スタイル**：ローポリ／フラットシェーディング寄り。マテリアルは PBR（glTF標準）でOK。
- **パーツ分け**：上表の「動くパーツ」は**別ノードに分け、同じ名前を付けて**ください。名前が一致していると、耳ピクッ・ホップ・車輪回転などのアニメをそのまま流用できます（一致しない場合は組み込み時に手で対応付けます）。

## アニメーションについて

現在のアニメ（耳ピクッ、ホップ、呼吸、車輪回転、旗揺れ、食事）は
`src/scene3d.js` がモデル内の該当ノードを毎フレーム動かして表現しています。
glb に差し替える際は、上表のノード名を合わせておくと流用が楽です。
ボーン／glTFアニメーションでの差し替えも可能ですが、その場合は組み込み時に個別対応します。
