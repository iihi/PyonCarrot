# ぴょんぴょんキャロット

ガラケー時代のFlashゲーム「フロフロフロッグ」をベースにした、ウサギとニンジン畑のパズルゲームのHTMLリメイクです。
Three.js によるローポリ3D・スマホ縦画面対応（PCはキーボード操作可）。

## あそびかた

- ウサギは、いま乗っている畑のニンジンの本数（1〜3）だけタテかヨコにジャンプ
- 飛び立った畑は消える。すべての畑を通ってから、ゴールで待つピンクのウサギのところへ
- ステージは「シード値＋ステージ番号」から自動生成（コード例: `1234-5` で共有・再開可能）

## 開発

```bash
npm install
npm run dev      # 開発サーバ (http://localhost:5173)
npm run build    # 本番ビルド → dist/
```

`dist/` の中身を静的Webサーバに置くだけで動作します（PHP等のサーバ側要件なし・サブフォルダ配置可）。
