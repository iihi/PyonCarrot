# UI（ボタン・ダイアログ）の画像スキン

ボタンやダイアログ枠は 3D でも Canvas 画像でもなく、**HTML/CSS で描画**しています。
そのため .glb / .png の「モデル・テクスチャ差し替え」とは別に、ここで**画像スキン**として差し替えます。

## 使い方

1. 差し替えたい部位の PNG（透過推奨）をこのフォルダに置く。
2. `manifest.json` に「部位キー → ファイル名」を書く。書いた部位だけ画像に差し替わる。
3. 書かなければ従来のグラデ/枠のまま（見た目そのまま・404 も出ません）。

`manifest.json` の例：

```json
{
  "btnPrimary": "btn-primary.png",
  "btn": "btn-green.png",
  "btnSub": "btn-sub.png",
  "panel": "panel.png"
}
```

## 部位キー一覧（`src/uiSkin.js` の `SKIN_VARS`）

| キー | 対象 | 使われている場所 |
| --- | --- | --- |
| `btn` | 通常ボタン（緑） | 「つづきから」「コード入力」など |
| `btnPrimary` | 主ボタン（オレンジ） | 「はじめから」「GO」「つぎのステージへ」など |
| `btnSub` | 副ボタン（グレー） | 「あそびかた」「とじる」「やめる」など |
| `panel` | ダイアログ枠 | 各モーダルの `.modal-box` |

## 制作ルール

- **伸縮**：画像は要素サイズに合わせて 100%×100% で引き伸ばして表示します（ボタンは幅が可変）。
  角が伸びて困る絵柄は、伸びても破綻しにくいデザイン（余白多め・角の主張控えめ）にしてください。
  ※将来 9 スライス（border-image）方式にも拡張できます。要望があれば対応します。
- **立体感の影**：ボタン下の立体的な影（押すと沈む表現）は CSS 側で描いています。
  画像はボタンの「面」を差し替えるイメージ。画像自体に濃い影を付けると二重になります。
- **色space**：普通に描いた見た目でOK（sRGB）。
- **ボタンの状態**：押下時は画像ごと少し沈みます（CSS の `:active`）。ホバー等の別画像は現状未対応。

現状の見た目を基準にしたい場合は、実機のスクリーンショットを参考にしてください
（UI は CSS 描画のため、モデル/テクスチャのような「書き出しツール」はありません）。
